# 일본 맛집 숏츠 지도

맛집 숏츠를 보다가 언젠가 가보고 싶은 일본 가게들을 지도에 꽂아 둔 개인 프로젝트입니다.

영문 보조명은 **Japan Shorts Food Map**입니다.

👉 https://lowbyyj.github.io/my-yt-japan-restaurant/

## About

이 저장소는 [Yongjae Yoo](https://lowbyyj.github.io/)의 개인 아이디어 실험 중 하나입니다.

연구와 업무에서는 무선 네트워크, 모바일 시스템, IoT, AI 응용을 다뤄 왔고, 개인 프로젝트에서는 일상에서 생기는 작은 문제나 흥미로운 데이터를 가볍게 제품 형태로 엮어보는 일을 좋아합니다.

이 프로젝트는 그중 하나로, 유튜브 숏츠를 보며 저장해 두고 싶어진 일본 맛집들을 지도에서 다시 찾기 쉽게 만드는 작은 지도입니다.

## Idea

- 숏츠에서 본 가게를 나중에 여행할 때 다시 찾기 어렵다.
- 링크와 위치를 지도 위에 모아두면 훨씬 직관적이다.
- 너무 거창한 서비스보다는, 개인적으로 쓰고 싶은 작은 도구를 먼저 만든다.

## Notes

- 개인용/실험용 프로젝트입니다.
- 수록된 장소와 정보는 시간이 지나며 달라질 수 있습니다.
- 각 카드의 영상 링크를 통해 원본 맥락을 확인할 수 있습니다.
- 지도와 장소 정보는 여행 참고용이며, 방문 전 최신 영업 정보를 확인하는 것을 권장합니다.
